Locked In

Arrival

The extension arms the briefing the first time you use the browser after this hour each day. It only fires once a day, and it never opens a window on its own — the next new tab delivers it.

Calendar feed

Paste the secret iCal address of your Google Calendar. It's read-only, needs no sign-in, and works from your phone too. Calendar only removes time from the evening and flags deadlines — it never creates a task.

  1. Google Calendar → hover your calendar in the left sidebar → ⋮ → Settings and sharing
  2. Scroll to Integrate calendar
  3. Copy Secret address in iCal format and paste it below

Anyone with this link can read your calendar, so keep it to yourself. Other calendar apps work too — Outlook and most school portals publish an .ics feed.

Phone sync

This is what makes the 3:00 upload land on your PC. Both devices read and write one key in a free Firebase Realtime Database. Leave it blank and everything still works — just on one device at a time.

  1. Go to console.firebase.google.com → Add project (free Spark plan is plenty)
  2. Build → Realtime Database → Create Database, and start in test mode
  3. Copy the database URL from the top of that page and paste it below
  4. Click New key, then put the same two values into the phone app

The key is the only thing protecting your list — test-mode rules let anyone who knows the exact path read it. Use the generated one, and don't post it anywhere. If you'd rather lock it down properly, set your database rules to {"rules":{"lockedin":{"$k":{".read":true,".write":true}}}} and treat the key as the password.

The pinned tab

Locked In lives in one pinned tab at the far left of your tab strip — a single favicon that survives restarts. It does not touch your new tab page. Ctrl+Shift+L jumps to it from anywhere.
